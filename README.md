# AI

Main AI repository collecting my machine learning, deep learning, and data
science work in one place. Each area lives under `subsets/`.

## Structure

- `subsets/machine-learning/` — classic ML algorithms (decision trees, KNN,
  k-means, logistic regression, random forest, PCA, reinforcement learning).
- `subsets/deep-learning/` — neural networks and deep learning projects
  (computer vision, chatbots, loan-risk modeling, Q-learning).
- `subsets/data-science/` — applied data science: EDA, forecasting, analysis.
- `stats/` — statistics notes and experiments (work in progress).

Each subset keeps its own per-project folders and READMEs.
