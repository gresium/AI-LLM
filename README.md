# AI-LLM

Author: Gresa Hisa

---

This repository contains all my work across artificial intelligence, machine learning, deep learning, reinforcement learning, data science, and web scraping. Each subject area has its own dedicated folder — projects, code, datasets, and documentation all kept together per topic. Nothing is mixed between categories.

The `resources/` folder is completely separate from the project work. It exists purely as a reference — a collection of open source models, public datasets, and tools worth knowing about, independent of anything built here.

---

## Subsets-of-AI

The core AI and ML work lives here, split into three dedicated subfolders.

**machine-learning/** — classical machine learning algorithms built, tested, and documented. Covers decision trees, KNN, k-means clustering, logistic regression, random forest, PCA, and support vector machines. Each algorithm includes an explanation of how it works, when to use it, and working code with example datasets.

**deep-learning/** — neural network architectures and applied deep learning projects including computer vision, chatbot development, and loan-risk modeling. Each project documents architecture choices, training process, results, and full source code.

**reinforcement-learning/** — RL theory and practical implementations covering Q-learning, reward function design, policy exploration, and environment setup. Concepts and code kept together.

---

## Data Science

Applied data science projects and statistical work. Covers exploratory data analysis, feature engineering, statistical modeling, forecasting, hypothesis testing, and visualization. Stats material lives here too — probability theory, distributions, and statistical inference documented alongside the applied work since the two are closely related. Each project includes the dataset and all code used.

---

## Web Scraping

Scripts and projects built to collect and automate data gathering. Used to build custom datasets where public ones did not exist or were insufficient. Built with BeautifulSoup, Requests, and Selenium depending on the target. Kept separate from data science since scraping is its own discipline.

---

## Resources

A standalone reference collection with no direct connection to any project in this repository. Exists for anyone who wants a starting point.

**open-source-models/** — links and notes on open source AI and ML models from Hugging Face, Ollama, and similar platforms.

**public-datasets/** — links to datasets from Kaggle, UCI ML Repository, government open data sources, and other public repositories.

**tools-and-libraries/** — a curated reference list of libraries, frameworks, and tools relevant to AI, machine learning, and data science work.

---

Each folder maintains its own structure with per-project subfolders containing code, datasets, and documentation kept together.
