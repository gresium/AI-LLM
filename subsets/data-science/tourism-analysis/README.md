# datascience-tourism-analysis

# Tourism Data Science Project

This repository contains an end-to-end data science exploration of tourism-related datasets.
The project includes data preprocessing, exploratory analysis, visualizations, and model experiments
implemented in a Jupyter Notebook.

##  Key Features
- Exploratory Data Analysis (EDA)
- Visualization of tourism trends
- Data cleaning and preprocessing pipeline
- Model experimentation for forecasting / classification

##  Structure
- `notebook/` — main Jupyter Notebook
- `src/` — (optional) Python modules for scaling the project
- `data/` — dataset storage
- `requirements.txt` — Python dependencies

##  Usage
Clone the repo:

git clone https://github.com/gresium/datascience-tourism-analysis.git

Launch the notebook:
jupyter notebook notebook/Datascience_Tourism.ipynb
