# Data-Science

Author: Gresa Hisa

---

This folder contains applied data science projects, statistical analysis work, and theoretical foundations. Each subfolder is its own self-contained project or topic area with code, datasets, and documentation kept together. More projects will be added over time.

---

## Projects

**Sales-Forecasting** — Time-series forecasting model built to predict future sales based on historical data. Covers data cleaning, trend and seasonality decomposition, feature engineering, and model evaluation. Built with Python, Pandas, and scikit-learn.

**Tourism-Analysis** — Exploratory data analysis on tourism datasets. Covers data wrangling, visual analysis of travel trends, regional comparisons, and statistical summaries. Uses Pandas, Matplotlib, and Seaborn.

More projects coming — covering classification, clustering, anomaly detection, and real-world dataset analysis.

---

## Statistics

Theoretical and applied statistics material. Covers the mathematical foundations that underpin data science and machine learning:

- Descriptive statistics: mean, median, variance, standard deviation, distributions
- Inferential statistics: hypothesis testing, p-values, confidence intervals
- Probability theory: Bayes theorem, conditional probability, probability distributions
- Correlation and regression: linear relationships, covariance, Pearson and Spearman correlation
- Statistical modeling: fitting distributions to data, goodness of fit

Includes worked examples with real datasets alongside the theory.

---

## Tools and Stack

All projects use Python as the primary language. Libraries and environments used across this folder:

- **Pandas** — data manipulation and cleaning
- **NumPy** — numerical computation
- **Matplotlib / Seaborn** — visualization
- **scikit-learn** — machine learning models and preprocessing
- **SciPy / statsmodels** — statistical testing and modeling
- **Jupyter Notebooks** — exploratory analysis and documentation
- **Google Colab** — cloud-based notebooks, used for heavier computation and sharing

Each project folder contains its own README with a full breakdown of the problem, methodology, results, and how to run the code.
